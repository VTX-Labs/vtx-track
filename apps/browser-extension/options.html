vtx-track

Tab-granularity time tracking for the local vtx-track daemon.

Report the active tab's domain to the daemon.
Off by default for privacy. Even when on, no URL path or query is ever sent.
One domain per line. A domain and all of its subdomains are never reported.

Privacy: only the registrable domain (e.g. github.com) is sent, and only to http://127.0.0.1:7842 on this machine. No full URLs, no telemetry, no cloud.
